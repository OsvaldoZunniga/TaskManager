# TaskManager
## Desarrollar un sistema de gestion de tareas ##
Este debera incluir:
- Login
- Generar tasks
- Recordatorios por email
- DeadLine en cada task
- Creacion de proyectos.
- Asignacion de usuarios a tareas y creacion de proyectos grupales
- Status in each task

### Tegnologias ###

##### Frontend: ####
- ReactJs+TS (Registrarse / iniciar sesión / Tasks)
- Sass->GridToResponsive
##### Backend: ####
- NodeJs+Express(Routes/RES/CRUD/JWT)
- FireBase & MongoDB (DataBase/Notifications)
